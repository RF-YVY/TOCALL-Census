How To Use TOCALL Census

1. Choose What To Track

Enter a TOCALL such as APDW16 to track one application or radio family, or leave the TOCALL field blank to count all traffic that matches your APRS-IS filter.

2. Set An APRS-IS Filter

Use a geographic filter such as r/34/-89/250 for a regional census, r/0/0/9999 for worldwide traffic, t/p for position packets, or combine them as r/34/-89/250 t/p.

3. Connect

Click Connect to start receive-only monitoring. A callsign and APRS-IS passcode are optional for this app; the default N0CALL and -1 values identify it as an unverified receive-only client.

4. Read The Results

Top TOCALLs shows software and radio adoption. Found in shows US states and countries using unique located packets, so duplicate raw packets are not counted. Live Packets shows raw packet evidence. Heard Positions maps packets that include standard uncompressed APRS coordinates.

5. Start Fresh Or Export

Use Clear Session before tracking a new TOCALL when you want an empty count table, packet list, and map. Use Export PDF, JSON, or CSV to save the current report.

6. Optional Identity

Open Advanced APRS-IS identity only if you want APRS-IS servers to see your callsign in their logs. It is not required for decoding or counting TOCALL traffic.

7. Keep The Registry Fresh

Refresh Registry downloads the APRS Foundation device identification database so codes like APDW16, APK003, and APAT81 resolve to human-readable device names.
